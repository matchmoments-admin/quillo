# Security vulnerability sweep, October 2026

Run on 2026-10-24 against `main` at `37117ab` and the live app (`app.quillo.au`). This sweep resolves
ticket [#694](https://github.com/matchmoments-admin/quillo/issues/694) on map
[#692](https://github.com/matchmoments-admin/quillo/issues/692), and is evidence for control
[4(c)](control-matrix.md) and the cl 1.6 testing program ([vulnerability-management.md](vulnerability-management.md)).

**Result: no CRITICAL or HIGH findings.** Of the 21 findings (status updated 2026-10-24, after the sweep):
- 8 are fixed in PRs (the original 5, plus S-04, S-08 and S-09, whose issues #712, #713 and #714 have shipped);
- 1 is closed as not planned: S-03 (#711), because the receipt mailbox is retired;
- 3 are owner or existing-ticket actions;
- 9 are accepted with a reason.

At the time of the sweep the split was 5 fixed, 4 new issues, 3 owner actions and 9 accepted.

No cross-tenant read, auth bypass or payment forgery was found.

## Checked and clean

- **Identity.** `stubFor()` is only ever called with a server-derived id. The sources are the Clerk `sub`, the HMAC key's `tenant_keys.user_id`, the mailbox lookup, the consumed OAuth state, Stripe-signed metadata (set from the session's `uid` at checkout) and cron rows. No header, query or body field selects a tenant. The Agents-SDK route (`routeAgentRequest`) is not mounted.
- **D1.** Every query on a tenant table is either scoped by `user_id`, or updates an id that came from a scoped lookup or is a server-generated UUID.
- **R2.** Every key is built on the server under `${userId}/…`. Reads go through `user_id`-scoped rows, and a client-supplied PHI `receipt_key` must start with `${userId}/phi/`. Purge sweeps the tenant prefix.
- **Auth.**
  - Clerk tokens are verified with jose `jwtVerify` against JWKS (asymmetric only, so `alg: none` is refused), with issuer, `exp` and `nbf` enforced and `azp` checked when present.
  - `DEV_AUTH_BYPASS` needs the exact string `"1"` and only applies when `CLERK_ISSUER` is unset. `CLERK_ISSUER` is set in `wrangler.toml`, `DEV_AUTH_BYPASS` is not a prod secret (checked by name), and check-units guards that `wrangler.toml` never assigns it.
  - Roles are read from D1 on the server and written only by the admin route.
- **Stripe.**
  - The HMAC is computed over the raw body and compared in constant time.
  - A missing secret returns 503 and credits nothing.
  - `credit_ledger UNIQUE(user_id, ref)` makes a replayed event credit once.
  - The client controls only the amount it pays.
- **APP-8 and residency.** All 14 `getLLM` callers check `consent_xborder` before the call. `getLLM` refuses `cdr_tainted` tenants on any provider other than Bedrock. Bedrock re-checks the region before signing and never reroutes on retry. There is no direct `api.anthropic.com` fetch.
- **Prompt injection.** Every model call is pinned to a single record-only tool via `tool_choice`. No tool sends mail, fetches a URL or reaches another tenant. Chat `proposed_actions` are validated against the turn's digest and the tenant's own ids (`extract.ts:1587-1640`), and the user has to apply them.
- **SSRF and redirects.** Every outbound URL is fixed or comes from env. Basiq/Fiskil pagination is pinned to the provider origin and path. OAuth callbacks redirect to `${origin}/<fixed path>`. There is no open redirect.
- **Bombs.** Nothing unzips or parses user archives. `gunzip` only runs on objects the server gzipped itself.
- **Transport.** Live response headers, checked 2026-10-24:
  - HSTS `max-age=31536000; includeSubDomains`;
  - an enforcing CSP with `frame-ancestors 'none'`;
  - `X-Frame-Options: DENY`, `nosniff`, `Referrer-Policy` and `Permissions-Policy`.

  `/api/*` returns 401 with no CORS headers, even for a foreign-origin preflight. Auth is a Bearer header only, with no cookies, so CSRF doesn't apply to `/api`.
- **Bank provider entry points.** There are no Fiskil or Basiq webhooks. The only public entry is `/api/bank/callback`, which is flag-gated and needs a single-use state.
- **Crons.** Each tenant runs through its own stub with scoped queries and per-tenant failure isolation. Paid backfills check the global cost ceiling first.
